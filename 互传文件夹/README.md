# 互传文件夹

适用于当前手机提供的互传网页版 `web2.1.0.9`，支持图片模块（相册页）和视频模块。

将 `script.js` 的完整内容替换到 Tampermonkey 中原有的“互传网页版：视频文件夹”脚本，保存后刷新互传网页。新脚本名称为“互传网页版：文件夹”，版本为 `1.2.0`。不要同时启用旧版和新版。

- 按文件的实际存储路径列出文件夹，支持搜索、多选、合并显示和恢复全部。
- 图片和视频分别保留当前的文件夹选择和搜索条件。
- 图片在“全部”模式下保留原生相册；勾选目录后合并显示所选目录中的图片。
- 沿用原网页的预览、选择、下载、删除和排序入口。合并图片沿用响应中的相册顺序及相册内排序。
- 更改筛选会清空当前模块的文件选择；加载、弹窗和图片全屏预览期间禁止切换筛选。

脚本匹配 `http://192.168.1.91/*`，端口变化不需要修改；手机 IP 变化时需更新 `@match`。

运行回归测试：

```powershell
node --test '互传文件夹/script.test.cjs'
```
