# 抖音下载

`douyin-download.user.js` 是独立的 Tampermonkey（油猴）脚本，和“小红书下载”一样，无需构建或安装 npm 依赖。

## 使用

1. 在打开抖音的浏览器中，通过油猴“添加新脚本”粘贴 `douyin-download.user.js` 的全部内容并保存。
2. 刷新已登录的抖音页面，进入个人主页 → 喜欢，例如 `https://www.douyin.com/user/self?from_tab_name=main&showTab=like`。
3. 点击作品卡片左上角的「↓ 下载」。黄色“已下载”按钮常显，无需悬停；未下载的喜欢列表按钮保持常显，“TA的作品”按钮在悬停卡片或键盘聚焦时显示，下载期间保持显示，触摸设备保持可见。视频保存 MP4；图集按顺序逐张保存，实况仅保存静态图片。滚动加载的新卡片也会添加按钮。

同样支持作者主页和播放弹层中的“TA的作品”卡片，包括没有独立详情链接、使用 React 点击事件切换作品的卡片。更新到 1.2.3 后，在油猴中替换原脚本并保存，再刷新页面即可。1.2.1 修复了作者头像可能被误识别为作品卡片的问题；1.2.2 将黄色“已下载”按钮改为常显；1.2.3 改为任一文件保存成功即标黄，保留已有下载标记。

下载按钮会显示进度；图集部分失败后再次点击，只重试当前会话中未成功的图片。全部完成后再点，可以重新下载。文件保存在浏览器设置的下载目录，文件名为 `作者_文案_作品ID_序号.实际格式`；本仓库的“抖音下载”是脚本存放目录。

任一文件保存成功后，按钮立即变为黄色并持久标记“已下载”；图集只保存一张、其他图片失败或取消，也保留黄色标记。全部失败或全部取消、没有文件保存成功时不新增标记。黄色表示曾保存过该作品的资源，不代表图集完整；部分失败会显示已保存数量，仍可点击补下当前会话中未成功的图片。使用 `GM_getValue/GM_setValue` 按作品 ID 保存到油猴持久存储，不设过期时间；关闭窗口、重启浏览器后仍恢复标记。新出现的同一作品、切换页面或重新聚焦窗口时也会读取标记，复用为另一条作品的卡片不会继承黄色。旧版未记录的历史下载无法自动补标；清除脚本存储或卸载时删除数据会丢失标记。

油猴需允许访问抖音和媒体 CDN，并启用下载功能（下载模式选择“浏览器 API”）。若提示扩展名白名单，允许 `mp4/jpg/png/webp/gif/avif/heic`。脚本安装后需要刷新已有标签页才能生效。

## 数据与边界

- 优先读取当前卡片 React props 中对应作品 ID 的数据，其次读取页面初始状态、JSON 脚本，最后携带当前登录会话读取对应作品详情 HTML。无需填写或导出 Cookie，不使用第三方解析服务，也不构造需要签名的私有 API 请求。
- 兼容 `aweme_id/awemeId`、`play_addr/playAddr`、`url_list/urlList`、`bit_rate/bitRate` 等字段。19 位作品 ID 全程保持字符串。
- 视频优先采用页面提供的高分辨率、高码率地址，失败后尝试其他页面提供的地址。保留签名参数，不承诺去水印、作者源文件或特定画质；不读取卡片封面作为视频，不处理 `blob:`、M3U8、DASH 分片、付费或加密长视频。
- 图集只读取图片条目的静态地址，不读取其中的实况视频。没有详情地址时明确报错，不把列表缩略图冒充完整图片。
- 请求限定抖音和列出的字节媒体域名；下载前校验 HTTP 状态、最终域名及文件头，防止将验证页面保存为视频或图片。不执行 HTML 中的脚本。
- 当前实现依赖网站卡片链接及 React 数据结构。如果作品数据缺失，先打开该作品再返回列表重试。遇到风控、登录或权限限制，需在网页正常处理后重试。
- “TA的作品”通过封面附近 DOM 自身的 React props 识别单条作品，不沿 Fiber 父节点猜测 ID；发现多条不同作品时拒绝把列表容器当作一张卡片。卡片复用时重新读取当前作品 ID。
- 作者头像、头像组件和指向 `/user/` 的个人主页入口不添加下载按钮。React 兜底识别还必须核对候选图片与作品视频封面或图集图片的地址；仅仅持有当前作品 ID 的头像、控制区不能生成按钮。

## 验证

```powershell
node --check '抖音下载/douyin-download.user.js'
node --test '抖音下载/douyin-download.test.cjs'
```

26 项离线测试覆盖作品匹配、字段兼容、清晰度选择、图集静态图片、JSON 解析、媒体文件头、备用地址、下载权限、“TA的作品”无链接卡片识别、悬停条件、复用、按钮点击、保存，以及脚本重载后的持久标记恢复、保存一张后立即标记、其余取消仍保留标记、全部取消不新增标记。头像回归涵盖：头像持有完整作品数据和已下载记录、个人主页链接、头像语义、作品封面与图集封面继续显示下载按钮。

当前内置浏览器标签页可被识别，但读取页面连续超时，尚未在用户的实际“喜欢”与“TA的作品”列表上完成浏览器验证。浏览器回归应检查：左上角按钮、点击不打开作品、视频实际播放、图集完整、滚动新增卡片、列表复用卡片后下载对应新作品、失败重试、下载权限提示。

解析结构参考：[media-parser 的抖音解析文档](https://github.com/ucmao/media-parser/blob/main/docs/parsers/douyin.md)。实际数据以页面提供内容为准。
